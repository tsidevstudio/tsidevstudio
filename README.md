# TSI Dev Studio

Independent Android developer building privacy-focused, local-first apps.

I create Android applications designed around simple ownership, fewer unnecessary accounts, less dependence on cloud services, and more control over personal data.

## Featured app

### Xsilent — Private Photo & File Vault

Xsilent is a privacy-focused Android vault for photos, videos and PDFs.

Key features:

- Local AES-GCM encryption
- No account required
- No ads
- No cloud storage for the vault
- Dynamic Decoy PIN with a separate decoy vault
- Biometric protection and automatic locking
- Encrypted backup
- Encrypted Trash
- Private PDF viewer
- Clean Share with metadata removal and blur tools
- Screenshot and screen-recording protection
- Quick Lock
- Local-first design

## Nullun — Status Bar Studio for Android

Nullun is an Android tool for creating customizable status-bar visuals and battery-screen mockups directly on-device.

Key features:

- Battery level from 1% to 100%
- Android- and iPhone-inspired styles
- Custom carrier text
- LTE, 4G and 5G indicators
- Custom signal and Wi-Fi indicators
- Custom messages
- Notification text controls
- App name controls
- Background customization
- Local on-device creation
- Free creation, editing, preview and History
- Lifetime unlock for external output
- No subscription
