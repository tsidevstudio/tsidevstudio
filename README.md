## Featured project

### Xsilent — Private Photo & File Vault

Xsilent is a privacy-first Android vault for photos, videos, PDFs and private files.

**Designed around local control:**

- No required account
- No ads
- No required cloud storage
- PIN and supported biometric access
- Decoy PIN
- Encrypted backup
- Encrypted Trash
- Private PDF viewing
- Clean Share privacy tools
- Quick Lock and automatic locking
- Screenshot and screen-recording protection where supported

## Development principles

TSI Dev Studio products are generally designed around:

- Local-first operation where practical
- No unnecessary accounts
- Minimal data collection
- Clear privacy expectations
- Reduced unnecessary cloud dependence
- No advertising where possible
- One-time ownership options where practical
- Focused Android utilities
- Straightforward user control

## Public repositories

TSI Dev Studio repositories are used for public product information, documentation, verification links, release resources and project discovery.

Unless explicitly stated otherwise, the Android application source code is not published in these repositories.

Security-sensitive implementation details, internal architecture and private product logic are intentionally excluded from public documentation.
